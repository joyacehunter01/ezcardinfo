# Contribution Guidelines

Thank you for your interest in contributing to ezcardinfo! We welcome all contributions that improve the project.

## How to Contribute

- Fork the repository.
- Clone your fork locally.
- Create a new branch for your feature or bug fix.
- Make your changes with proper documentation.
- Test your changes before submitting.
- Submit a pull request to the main branch.

## Reporting Issues

If you find a bug or issue:
- Check if it already exists in the issues section.
- If not, create a new issue.
- Provide a clear description, steps to reproduce, and screenshots if possible.

## Suggesting Features

We appreciate new ideas!
- Open an issue with the label "Feature Request".
- Clearly explain the feature and its benefits.
- Provide examples if possible.

## Code of Conduct

- Be respectful and inclusive.
- Avoid offensive or harmful language.
- Collaborate positively with other contributors.

## Review Process

- All pull requests will be reviewed by maintainers.
- Feedback may be provided for improvements.
- Once approved, changes will be merged into the main branch.
